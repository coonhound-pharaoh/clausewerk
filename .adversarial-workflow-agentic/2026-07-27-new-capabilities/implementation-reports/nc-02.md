## What each endpoint defers to

Every entry names the rule it defers to and checks nothing itself. `opened_by`,
`baseline_chosen_by` and both `actor` columns come from `current_setting('cw.actor')`; no
ownership test, no role comparison and no restatement of a schema constraint appears in Python:

- the `to_state` list stays in the table's check constraint — the move endpoint does not restate it;
- the renewal baseline default stays in `cw.governance_setting` — an absent `baseline` is passed
  through as null, which is what "the recorded default" means;
- the round sequence guard stays in `cw.round_is_next()`;
- the opening movement row stays in `cw.position_opens()` — the positions endpoint writes no
  movement, which is the double-recording trap the package named, and a test counts the rows;
- **no endpoint writes an audit row.** `cw.audit_negotiation()` fires on insert into all four
  tables (`0011:337-343`), so an endpoint-side audit write would record every act twice.

## Deviations and ruled disagreements

1. **One test was inverted against the package's own expectation, and this is the substantive
   finding.** The package's risk register said POST /negotiations/renew was the one endpoint whose
   refusal test might pass for the wrong reason, because `cw.open_renewal` is SECURITY DEFINER and
   runs past the policies NC-01 installed — and instructed: assert its scoping deliberately, and
   if it does not hold, say so rather than removing the test. It was asserted, and **it holds**:
   NC-03 has already landed, and a stranger opening a renewal on somebody else's deal is refused
   with an ownership refusal from the database. The test written to record the hole was rewritten
   as the refusal test, with the owner's identical call succeeding alongside it so the refusal is
   demonstrably about ownership rather than about a broken endpoint.

2. **The package's scope named `backend/doorway/test_writes.py`; the session brief suggested
   `test_negotiations.py`.** Followed the package. The refusal, actor and one-act checks that
   already walk every `WRITES` entry pick the six new endpoints up automatically only if they live
   in that file's `BODIES` — a separate file would have left those six out of eleven existing
   parametrised checks.

3. **`paper` is a required field on both /negotiations and /negotiations/renew**, although
   `cw.open_renewal` defaults it to `'ours'`. psycopg binds positionally, so passing the parameter
   at all means passing a value; defaulting it in Python would have put a second copy of the
   schema's default in the doorway. Requiring the caller to state whose paper it is duplicates
   nothing.

4. **`baseline` is required on POST /negotiations** for the same reason: the column has a NOT NULL
   with a schema default, and a Python default would be a second copy. On /renew it stays optional,
   because there null is meaningful — it is what selects the recorded governance default.

5. **No content was tested.** Refusal tests assert that a refusal happened, that it carries words,
   and that it was not a missing-field rejection. They never assert which words.
